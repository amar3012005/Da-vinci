CORE DELIVERABLES (2 files, 552 lines of code)
================================================================================

1. src/components/hivemind/app/hooks/useGraphState.js (328 lines)
   - Purpose: Manage live graph state with non-blocking mutations
   - Export: useGraphState(sessionId) hook
   - Key features:
     * nodes: Record<nodeId, node> - O(1) lookup
     * edges: Record<edgeId, edge> - O(1) lookup  
     * layerIndex: Record<layer, Set<nodeId>> - O(1) filtering
     * handleGraphEvent(event) - router for graph.*.* events
     * clearGraph() - reset for new session
     * queueMicrotask() - non-blocking mutations
   - Supported events:
     - graph.node.created (nodeId, type, title, val, color, layer, metadata)
     - graph.edge.created (edgeId, source, target, type, color, confidence)
     - graph.node.layer_updated (nodeId, layer)
   - Edge cases handled:
     * Duplicate node IDs (overwrites silently)
     * Orphan edges (stores but doesn't render until target exists)
     * Rapid bursts (queued and batched)
     * Layer filter during streaming (retroactive updates)

2. src/components/hivemind/app/components/LiveGraphPanel.jsx (224 lines)
   - Purpose: Connect SSE stream to real-time graph visualization
   - Export: LiveGraphPanel(props) component
   - Key features:
     * useGraphState integration
     * Layer filtering UI (8 toggles: sources, claims, trails, blueprints, 
       observations, csi-nodes, csi-verdicts, execution-events)
     * Orphan edge handling (filters to visible endpoints)
     * ForceGraph data conversion
     * window.__liveGraphPanel[sessionId] exposure for SSE integration
   - Props: sessionId, width?, height?, onNodeClick?, onNodeHover?
   - Renders: <GraphVisualization /> with live data

EDGE CASES HANDLED (4/4 critical cases)
================================================================================

Case 1: Duplicate Node IDs
  Input: Two events with nodeId='source-1'
  Behavior: Silent overwrite (v2 replaces v1)
  Status: HANDLED

Case 2: Orphan Edges (target doesn't exist yet)
  Input: Edge with source/target before target node created
  Behavior: Stored but not rendered until target arrives
  Status: HANDLED

Case 3: Rapid Event Bursts (100+ per second)
  Input: 100 graph.node.created in 1ms
  Behavior: All queued, batched into single state update
  Status: HANDLED

Case 4: Layer Filter During Streaming
  Input: Events arrive while toggling layer visibility
  Behavior: Events update layerIndex retroactively
  Status: HANDLED

INTEGRATION REQUIREMENTS
================================================================================

Frontend (DeepResearch.jsx):
  1. Import LiveGraphPanel component
  2. Render <LiveGraphPanel sessionId={sessionId} /> in graph tab
  3. Wire SSE handler: window.__liveGraphPanel[sessionId].handleGraphEvent()
  4. Call clearGraph() on new session

Backend:
  1. Emit graph.node.created events during research
  2. Emit graph.edge.created events as edges are created
  3. Optionally emit graph.node.layer_updated for layer migrations
  4. Use exact event structure specified in PHASE1_INTEGRATION_GUIDE.md

Browser:
  1. Modern browser with ES2020 support
  2. React 16.8+ (for hooks)
  3. react-force-graph-2d (already in use)
  4. EventSource support (SSE)
