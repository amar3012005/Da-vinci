# SINGULANCE HIVE-MIND entrypoint

Use this folder before altering the Da-vinci web shell or Cloudflare Worker.
Read `CONTRACT.json`, fetch the pinned canonical contract, and select one owner
in `ROUTING.json`. A lower-tier executor may change only the files and run only
the commands in a validated task manifest. Release work requires the canonical
release manifest, an artifact-specific canary, and rollback evidence.

This folder deliberately does not copy platform rules. Do not create another
agent-instruction tree or treat historical project notes as release authority.
