# Runtime characters v1

Six Runtime-only characters from the generated 2026-10-19 pose sheets. These assets do not replace employee Humation avatars.

160px WebP derivatives of the original 384px pose-animation pack. `stills/` is the identity fallback; `animations/` contains the matching four-second loops. The Runtime settings preview uses ready animation with OS reduced-motion fallback. Sidebar/chat portraits use the static ready pose. Other state assets are retained for consumers with explicit status evidence.

This versioned directory is immutable after release. A new derivative set needs a new version directory and bounded backend validator change. `manifest.json` records the hash of every output.
